# 全局语义分析

你正在处理一段中文口播视频的转写文本。请提取以下全局语义信息。

**你只负责提取全局上下文，不要纠错，不要删内容，不要输出剪辑建议。下游的 segment 级纠错和去重 prompt 会自行判断，你只需提供它们无法自推导的全局信息。**

## 输入

以下是完整的转写文本（所有 segments 拼接）：

{{transcript_text}}

## 任务

### 1. 全文摘要

用 2-3 句话概括全文核心内容。不是复述结构，而是提炼文章在讲什么——核心论点、主要议题、说话人的立场。

下游去重 prompt 需要这个锚点来判断"同一句话换方式重复两遍"是口误还是刻意强调。例如知道"全文核心论点是明天高开低走"的 LLM，比只知道 topic="财经"的 LLM 更能判断某个片段的语义方向是否与全文一致。

### 2. 视频话题

判断视频所属领域/话题（如"财经复盘"、"装修教程"、"教育科普"等），为下游纠错提供领域消歧锚点。

### 3. 说话人自称

找出博主/主播在文中反复使用的自称。由于 ASR 识别不稳定，同一个自称可能出现多个变体。你需要：

- 列出所有变体到 `speaker_aliases`
- 从中选出一个**最可能是标准写法的**作为 `canonical_speaker_name`，并给出置信度
- 判断依据：出现频率最高、最简洁、最像真实人名的那一个
- 如果没有明确的自称模式（比如博主用"我""我们"没有特定名字），`canonical_speaker_name` 留空，confidence 为 0

### 4. 全局不一致词（canonical_terms）

找出**全文出现 2 次及以上、ASR 每次翻译都不一样**的专有名词 / 固定表达 / 领域术语。这是全局层唯一关心的"纠错"信息——发现跨段的不一致模式，而非判断某一段内的具体对错。

**判断标准**：
- 同一个词在全文中出现多次，但 ASR 写出了不同的汉字变体
- 读音相同或相近（同音/近音词）
- 从全文语境可以确定一个最可能的标准写法

**示例**：

全文出现 3 次"定心丸"，ASR 分别识别为 "定性晚"、"定心丸"、"定心完" →
```json
{"canonical": "定心丸", "variants": ["定性晚", "定心丸", "定心完"], "evidence": "全文出现3次，为固定表达，ASR两次识别为错字", "confidence": 0.93}
```

全文出现 5 次"仓位"，其中 2 次 ASR 识别为"苍位" →
```json
{"canonical": "仓位", "variants": ["仓位", "苍位"], "evidence": "全文出现5次，为金融术语，2次ASR识别为'苍位'", "confidence": 0.95}
```

全文出现 4 次"股市"，其中 1 次 ASR 识别为"骨市" →
```json
{"canonical": "股市", "variants": ["股市", "骨市"], "evidence": "全文出现4次，为财经基础词，1次ASR识别为'骨市'", "confidence": 0.90}
```

**不标记的情况**：
- 全文只出现 1 次的词 → 没有"跨段不一致"可发现
- 每次出现都是相同写法的词 → 没有不一致
- 不确定标准写法的情况 → 不放入 canonical_terms

## 输出格式

严格输出 JSON：

```json
{
  "summary": "全文回顾今日A股大盘走势，核心论点是明天大概率高开低走，建议投资者逢高减仓。主要涉及技术面分析和政策面消息解读。",
  "topic": "财经复盘",
  "speaker_aliases": ["凡姐", "樊姐", "板也", "板姐"],
  "canonical_speaker_name": "凡姐",
  "canonical_speaker_confidence": 0.92,
  "canonical_terms": [
    {
      "canonical": "定心丸",
      "variants": ["定性晚", "定心丸"],
      "evidence": "全文出现3次，为固定表达，ASR两次识别为错字",
      "confidence": 0.93
    },
    {
      "canonical": "仓位",
      "variants": ["仓位", "苍位"],
      "evidence": "全文出现5次，为金融术语，2次ASR识别为'苍位'",
      "confidence": 0.95
    }
  ]
}
```

只输出 JSON，不要任何额外文本。
