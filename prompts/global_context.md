# 全局语义分析

你正在处理一段中文口播视频的转写文本。请提取以下全局语义信息。

## 输入

以下是完整的转写文本（所有 segments 拼接）：

{{transcript_text}}

## 任务

你只负责提取全局上下文，**不要纠错，不要删内容，不要输出剪辑建议**。

重点找：
1. 说话人自称（博主/主播怎么称呼自己）
2. 领域词和专有名词（金融术语、品牌名、项目名）
3. 固定表达（常见搭配、习惯用语）
4. 疑似 ASR 高频错词（在上下文中多次出现但可能是同音错词）
5. 视频话题（财经、装修、教育等）

不确定的内容放入 `uncertain_items`，不要自作主张。

## 输出格式

严格输出 JSON：

```json
{
  "topic": "视频话题简述",
  "speaker_aliases": ["博主自称1", "博主自称2"],
  "confirmed_terms": ["已确认专有名词"],
  "domain_terms": ["领域术语"],
  "possible_misrecognitions": [
    {"original": "板也", "suggested": "板姐", "evidence": "上下文多处出现'板姐'作为博主自称", "confidence": 0.92}
  ],
  "uncertain_items": [
    {"item": "某个品牌名", "question": "该品牌是否有固定写法？"}
  ]
}
```

只输出 JSON，不要任何额外文本。
